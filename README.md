# Coming soon

It's that time of the year again. This is the third time I am attempting to
write a complete graphics engine from scratch.

Last time it was [Nexavey](https://github.com/RaphaelAsla/Nexavey), and
although it was going well, I lost motivation to continue working on it for a
few reasons.

The first reason is kinda dumb: I accidentally deleted the whole repository
from my computer with a ton of changes that I didn't push. Looking back at
this, I really don't know why I wasn't pushing code more often on a dev branch.

The second reason is that I found a job as an embedded software engineer one
month after I started working on
[Nexavey](https://github.com/RaphaelAsla/Nexavey) (of the Vulkan port, to be
precise, as it was originally an OpenGL engine), and I was also starting the
2nd year of my CS bachelor's degree, so things got a little rough for me.

The third reason is that I was never fully satisfied with
[Nexavey](https://github.com/RaphaelAsla/Nexavey) because it was heavily based
on this
[tutorial](https://www.youtube.com/watch?v=Y9U9IE0gVHA&list=PL8327DO66nu9qYVKLDmdLW_84-yE4auCR).
It obviously contained original code written by me, but it never felt like
I truly owned the project.

So I decided to start over. This time, I feel like I can finally manage work,
university, and this project, and I want to do everything myself, using only
the official Khronos sources.

The goal of this project is for me to understand as much as I can about how the
API works and implement the theory I already know. I want to actually
understand what I'm doing rather than following a tutorial and building on top
of someone else's approach.

Then I will use that project to learn more advanced rendering concepts as I go.

I am also hoping that by the time I finish my degree (2 years left), this
project will be on a good enough level to get me a graphics programming job. I
like embedded, but it's not what I want to do for the rest of my life.
